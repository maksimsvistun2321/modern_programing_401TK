Inventory System - це система призначена для ведення обліку деяких предметів або товарів на складі.
Її основна мета забезпечити можливості для додаваня, зберігання та виведення основної інформації про об'єкти, які наявні в системі.
Також дана система повинна коректно опрацьовувати дії користувача, для прикладу, не дозволяти додавати від'ємну кількість речей та інше.
